# Shiptivitas — Kanban Board Feature Analysis

**Release date:** June 2, 2018

## Key Findings

The average number of daily active users increased from 3.35 before the Kanban Board release to 11.79 afterward, representing approximately 251.69% growth.

Additionally, 200 cards recorded status changes, indicating interaction with the Kanban workflow.

These results suggest increased engagement following the release, although other factors may have contributed to the growth.

## Feature Idea 1: Task Deadline Reminders

**Hypothesis:** Users will return to the application more frequently if they receive reminders about upcoming task deadlines.

**Expected Impact:** Increased daily active users and improved task completion rates.

**What the feature is:** Allow users to set due dates on Kanban cards and receive notifications before deadlines.

## Feature Idea 2: Team Collaboration

**Hypothesis:** Enabling team members to assign tasks and communicate directly on cards will encourage more frequent application usage.

**Expected Impact:** Higher daily engagement and increased collaboration.

**What the feature is:** Introduce card assignments, comments, and teammate mentions.

## Feature Idea 3: Progress Dashboard

**Hypothesis:** Users will be more motivated to return when they can easily track completed tasks and overall progress.

**Expected Impact:** Improved user retention and more consistent daily activity.

**What the feature is:** Create a dashboard displaying completed tasks, pending work, overdue cards, and weekly progress.

## Conclusion

The Kanban Board release was followed by a substantial increase in daily active users. The next development priorities should focus on encouraging repeat visits, improving collaboration, and helping users monitor their productivity.

The proposed features should be tested and measured against daily active users and retention.
